# Landing Page untuk Meta / kirim.dev

## File
- `index.html` — halaman utama
- `privacy.html` — kebijakan privasi
- `styles.css` — tampilan website

## Cara publish lewat GitHub Pages
1. Buat akun GitHub jika belum punya.
2. Buat repository baru, misalnya: `herbal-ai-cs`.
3. Upload ketiga file ini ke repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch **main** dan folder **/(root)**.
7. Klik **Save**.
8. Tunggu beberapa menit hingga GitHub menampilkan URL website.

Contoh URL:
`https://USERNAME.github.io/herbal-ai-cs/`

Masukkan URL tersebut ke kolom **Website** pada proses Meta / kirim.dev.

## Penting
Jangan menyatakan website ini sebagai website resmi sebuah perusahaan jika Anda belum mendapat izin.
Sesuaikan nama, email, deskripsi, dan identitas bisnis sebelum digunakan.
